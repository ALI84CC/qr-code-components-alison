### What I learned

I am very proud of the experience of developing a card using the mobile-first concept, which made me feel much more comfortable with the web development process. I used HTML, CSS, and Flexbox, creating a single style.css file to configure the entire page. 

As I strive to become better each day, looking back at my code, I realize that next time I could develop better-organized utility classes and avoid fixing the height of text blocks to achieve a natural text flow. 

### Continued development

The biggest challenge was controlling the behavior of the container to fix it perfectly within the viewport without breaking the page or creating unnecessary scrollbars. I overcame this problem by adjusting the width and height properties, applying overflow: hidden to the body element, and correcting the direction of the media queries. 

I intend to continue focusing on deep learning about responsive layouts using Flexbox and Grid, refining my knowledge of Mobile-First methodologies, and the correct usage of relative units to avoid layout breakage issues. 

### Useful resources

* [CSS Object-fit - Alura](https://www.alura.com.br) - This article helped me understand perfectly how to control the proportions of the QR Code card image without distorting it.

### AI Collaboration

For this project, I used the assistance of Google's Gemini model as a study partner and for Code Review. It helped me analyze the Box Model structure, identify incorrectly applied Flexbox properties, and fix the bug causing unnecessary horizontal page scrolling.
